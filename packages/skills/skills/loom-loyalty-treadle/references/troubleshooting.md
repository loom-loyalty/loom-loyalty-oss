# treadle troubleshooting

| Symptom                                                                  | Likely cause                                                                                                                                         | What to do                                                                                |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `... is not a valid loom-loyalty-config.v1 manifest:` followed by a list | The CLI's local check failed: wrong `schema`, bad `code`, unknown top-level key, a record without `code`, more than 500 records, or a duplicate code | Fix the line the message names. The path is shown like `eventRules[2].code`               |
| `<file>: not found`                                                      | Wrong path or working directory                                                                                                                      | Pass `-f <path>` or run from the folder with the file                                     |
| Feature unavailable or disabled for the organization                     | Configuration as code is early access and is turned on per organization                                                                              | Ask the developer to contact Loom Loyalty to enable it                                    |
| 401 from the API                                                         | Missing, revoked or expired credential                                                                                                               | Check `LOOM_API_TOKEN`. Create a new key in the dashboard if needed                       |
| 403 from the API                                                         | Key lacks the role or scope for a section the file declares                                                                                          | Use a key with the `org-admin` role, or one holding write scope for each declared section |
| `CONFLICT` naming another file                                           | Another file or a catalog package already owns the record                                                                                            | Remove the record from one of the two files                                               |
| `CONFLICT` naming a code                                                 | A reference points at a code that does not exist                                                                                                     | Declare that record in the file, or correct the code                                      |
| `CONFLICT` on a flow                                                     | The flow graph failed validation                                                                                                                     | Read the validator's message in the plan line and fix the graph                           |
| `BLOCKED`                                                                | The record is live and the key cannot change live records in that environment                                                                        | Use an `org-admin` key, or ask an admin                                                   |
| `hub:` error naming subdomain, custom domain, name or custom components  | Those belong to each environment's hub                                                                                                               | Remove them from the file and set them in Hub                                             |
| "Not applied: the plan changed since it was shown"                       | The organization changed between plan and apply                                                                                                      | Run `treadle plan` again, show it, and re-confirm                                         |
| "No terminal to confirm on; pass --yes"                                  | Non-interactive shell                                                                                                                                | After the developer has reviewed the plan, rerun with `--yes`                             |
| Browser login refused                                                    | `CI` is set                                                                                                                                          | Provide `LOOM_API_TOKEN`                                                                  |
| `pull` says the file exists                                              | Safety check                                                                                                                                         | Pass `--force`, or pull to another file with `-f`                                         |
| `status` shows a request stuck `PENDING`                                 | Nobody approved it in the dashboard                                                                                                                  | Approve it there, then rerun `treadle status`                                             |
| `plan` exits 2 right after `apply`                                       | Drift, or another process changed the record                                                                                                         | Read the `UPDATE` lines, decide which side wins                                           |
